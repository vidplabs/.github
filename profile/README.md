# Vidp Labs

We build **Vidp**, an open-source macOS video player powered by [libmpv](https://github.com/mpv-player/mpv).

## Projects

- [Vidp](https://github.com/vidplabs/vidp) — the macOS video player.
- [Vingine](https://github.com/vidplabs/vingine) — playback engine components for Vidp.
- [Homebrew tap](https://github.com/vidplabs/homebrew-vidp) — install Vidp with Homebrew.
- [Website](https://vidplabs.github.io/) — learn more about the project.

## Get involved

Explore the repositories, report issues, and contribute through GitHub. Visit [vidplabs.github.io](https://vidplabs.github.io/) for project updates.
